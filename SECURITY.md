# Security

Artifex has no installable implementation or released versions yet.

Report accidental disclosure or a security issue through
[GitHub private vulnerability reporting](https://github.com/GodfreyEngineering/artifex/security/advisories/new).
Do not put secrets or private evidence in a public issue. Include the affected file or commit and
enough detail to reproduce the issue safely.

The project does not offer a response-time commitment. Supported versions and security-update policy
will be documented with the first implementation release.
