# Contributor instructions

Read README.md, docs/scope.md and ROADMAP.md before making changes. This is a public, planning-stage
project. Do not describe intended capabilities as implemented or add installation commands before an
implementation exists.

Agree a written design before substantial code changes. Work in complete, reviewable slices and
verify observable behaviour. Keep provider-neutral instructions canonical; provider adapters should
refer to them.

Use British English. Keep credentials and private organisational material out of the tree and Git
history. Use synthetic fixtures and preserve third-party licence notices.
